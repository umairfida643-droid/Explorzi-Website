> **"THE JOURNEY IS THE DESTINATION"**  
> Official web platform for **Explorzi.pk** (operated under **TRAVEL with AM**), Lahore, Pakistan.

## Overview

**Explorzi.pk** is a premier domestic tour operator in Pakistan specializing in:
- **By-Air Luxury Escapes** to Skardu & Deosai (direct return flights).
- **Executive Group Adventures** to Hunza, Passu Cones, and Attabad Lake.
- **Kashmir & Northern Frontier Retreats** (Neelum Valley, Arang Kel, Swat, Malam Jabba, Fairy Meadows).
- **Private Custom Family Expeditions & Honeymoon Tours**.

---

## Key Features

- **Multi-Page Architecture:** Dedicated pages for Home, Tours Portfolio, Destinations Atlas, Interactive Custom Trip Calculator, About Us, and Contact Concierge.
- **Asymmetric Split Luxury Hero Section:** Editorial typography, verified operator trust metrics, and an interactive 3D featured expedition showcase.
- **Interactive Custom Trip Price Calculator:** Instant budget quotation based on destinations, duration, traveler count, vehicle category (Prado 4x4, Hiace Grand Cabin, Saloon Coaster, By Air), hotel rating, and add-ons (Bonfire & BBQ, Drone Videography, Mountain Safari Jeeps) with direct WhatsApp transmission.
- **Authentic Official WhatsApp Integration:** Official WhatsApp branding with a floating concierge widget and pre-filled reservation messages.
- **Zero Casual Emojis:** Refined with clean SVG vector icons and executive typography for an international bespoke travel agency feel.
- **3D Mouse Parallax & Tilt Physics:** Mouse-driven 3D perspective transforms with dynamic specular glare on expedition cards.
- **Light & Dark Theme Switcher:** Smooth theme transition with `localStorage` state persistence.
- **Official Brand Favicon & Logos:** Direct integration of the official Explorzi crest and multi-size favicon formats.

## Local Development & Preview

To run the website locally:

```bash
# Clone the repository
git clone https://github.com/umairfida643-droid/Explorzi-Website.git

# Navigate into the project folder
cd Explorzi-Website

# Start a local HTTP server using Python
python -m http.server 5000
```

Open your browser and navigate to:
**[http://localhost:5000](http://localhost:5000)**
